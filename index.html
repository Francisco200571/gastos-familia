¿Cómo conectar Supabase?

Para que todos en tu familia vean los mismos gastos, necesitas conectar una base de datos gratuita de Supabase. Solo toma 5 minutos:

1
Crea una cuenta gratis en Supabase

Entra a supabase.com y regístrate con tu cuenta de GitHub.

2
Crea un proyecto nuevo

Dale un nombre (ej. "gastos-familia"), elige región South America y pon una contraseña.

3
Crea la tabla de gastos

Ve a SQL Editor en tu proyecto y pega este código:

create table gastos ( id bigint generated always as identity primary key, fecha date not null, monto numeric(10,2) not null, categoria text not null, quien text not null, descripcion text not null, created_at timestamptz default now() ); alter table gastos enable row level security; create policy "acceso_publico" on gastos for all using (true) with check (true);
4
Obtén tus credenciales

Ve a Project Settings → API. Copia la Project URL y la anon public key.

5
Pégalas en el archivo config.js

Abre el archivo config.js que viene en el proyecto y reemplaza los valores:

const SUPABASE_URL = 'https://TU_URL.supabase.co'; const SUPABASE_KEY = 'TU_ANON_KEY_AQUI';
6
Sube a Vercel

Sube la carpeta a GitHub y desde vercel.com importa el repo. En 2 minutos tienes tu link listo para compartir con la familia.
